### **Why we import os \& sys?**

###### os is used to interact with the operating system.

###### 

###### **os** is used for interacting with the operating system — mainly for atomic file writes, directory management, and environment variables for secure configuration.

###### And **sys** is used to control runtime behavior such as returning exit codes for schedulers and handling command-line arguments. 

###### This ensures the ETL job is production-ready and orchestration-friendly.
